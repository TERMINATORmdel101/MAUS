# Logo de MAUS

`maus-logo.jpg` est le logo officiel fourni par le porteur du projet (2048 × 2048). Il n'est **pas** couvert par la licence GPL du code : voir [TRADEMARKS.md](../../TRADEMARKS.md).

Les images de l'application (`src/Maus.App/Assets` : icône, bannière) et `maus-logo-800.jpg` en sont tirées **par recadrage et redimensionnement seulement**, avec `python3 tools/make-logo-assets.py` (Pillow). Pour changer de logo : remplacer `maus-logo.jpg`, relancer l'outil, puis vérifier les cadrages.
